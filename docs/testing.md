## 2. Команди за възпроизвеждане на резултатите

```bash
# Изпълнение на всички автоматични тестове
npm test

# Изпълнение само на тестовете за сигурност
npm run test:security

# Изпълнение само на теста за отказ на дисков възел и излишък
npm run test:redundancy

# Изпълнение на End-to-End Smoke теста
npm run smoke
```
